# MCP_localDome
  这是测试MCP本地运行的Dome，接入的是Free_QwQ模型，需要自己去修改模型API以及密钥。测试的只有ESP32S3开发板的LED的开关，其他的以此类推。

  This is a test Dome for local running of MCP, which is connected to the Free_QwQ model. You need to modify the model API and key by yourself. Only the LED switch of the ESP32S3 development board is tested here. The rest can be done in the same way.
